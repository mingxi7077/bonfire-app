# 篝叫 Bonfire · Android 客户端

篝火（Bonfire）社区 Minecraft 服务器的官方 Android 客户端，含**统一电子银行**、社区交流、篝篝岛等模块。

本仓库用于**分发安装包与版本说明**；源码在其他私有仓库，不在此处公开。

---

## 什么是篝叫

篝叫是「篝火」生态的手机端入口。篝火是围绕多个 Minecraft 服务器（鸡腿岛、伊瓦尔大陆、白菜岛）构建的
中文社区，篝叫负责把社区、身份和游戏经济打通。

三个平台共用**同一本账**（中央账本服务），因此你在游戏里、在 App 里看到的余额永远是同一个数。

```
        ┌──────────────┐
        │   中央账本    │  ← 唯一真账，所有写入都经它
        └──────┬───────┘
     ┌─────────┼─────────┐
     ▼         ▼         ▼
  篝叫 App   游戏服务器   官网后台
```

### 关于安装包体积

2.0.x 的安装包明显大于 1.x（343 MB vs 74 MB），原因是**篝篝岛**用了原生 Godot 引擎：

| 组成 | 大小 |
|---|---|
| Godot 引擎（三个 CPU 架构各一份） | 210 MB |
| 岛屿资源包 `bonfire_island.pck` | 35 MB |
| Flutter 本体 + 应用资源 | 约 95 MB |

Godot 是完整的 3D 游戏引擎，这是原生运行岛屿的代价。后续版本会提供单架构包以减小体积。

## 下载与安装

### 方式一：App 内更新（推荐）

App 内「设置 → 版本与更新 → 检查更新」可直接下载安装。

### 方式二：手动下载

从本仓库 [Releases](../../releases) 页面下载最新 APK。

**稳定下载链接**（永远指向最新版本）：

```
https://github.com/mingxi7077/bonfire-app/releases/latest/download/bonfire-app-latest.apk
```

### 安装说明

1. 下载 APK 后用文件管理器打开
2. Android 会提示"未知来源应用"，需在设置里允许一次
3. Android 8 及以上会引导你打开对应的权限页面
4. 安装包与旧版签名一致，可直接覆盖安装，不会清除登录状态

**系统要求**：Android 7.0（API 24）及以上，建议 Android 10 以上。

## 校验下载完整性

每次下载后建议核对 SHA256，避免网络传输损坏或文件被替换。

**PowerShell：**
```powershell
Get-FileHash .\bonfire-app-latest.apk -Algorithm SHA256
```

**macOS / Linux：**
```bash
shasum -a 256 bonfire-app-latest.apk
```

把结果与对应 Release 说明里的 SHA256 对比，一致即可安装。

## 常见问题

**Q：为什么 GitHub 下载很慢？**
A：GitHub 在国内访问速度不稳定。App 内更新走的是国内云存储，速度正常；GitHub 仅作为备用镜像。

**Q：安装时提示"应用未安装"？**
A：通常是旧版本签名不一致，或下载不完整。先校验 SHA256，再尝试卸载旧版后重装（卸载会清除本地登录状态）。

**Q：余额显示和游戏里不一致？**
A：正常情况下应当完全一致——三个平台共用一本账。若不一致请立刻反馈，属于需要排查的异常。

**Q：篝石是什么？**
A：篝火生态里的另一种货币，当前未开放，界面中显示为锁定状态。
